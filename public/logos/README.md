# Logos — Meta Consultoria

Todas as logos estão em **PNG com fundo transparente** (alta resolução, extraídas do slide guide oficial). O símbolo também tem versão **vetorial em SVG** para escalabilidade infinita.

| Arquivo | Versão | Fundo recomendado |
|---|---|---|
| `lockup-light.png` | Meta + ▽ + CONSULTORIA — texto navy | Claro (paper / branco) |
| `lockup-dark.png`  | Meta + ▽ + CONSULTORIA — texto branco | Escuro (navy) |
| `wordmark-light.png` | Meta + ▽ — texto navy | Claro |
| `wordmark-dark.png`  | Meta + ▽ — texto branco | Escuro |
| `symbol.png`  | ▽ gradient isolado, transparente | Qualquer |
| `symbol.svg`  | ▽ gradient vetorial, sempre nítido | Qualquer |

### Boas práticas

- **Margem livre:** mínimo igual à altura da letra "M" do wordmark.
- **Tamanho mínimo:** 24px de altura para o símbolo, 80px para o lockup.
- **Não distorça**, não recolora, não aplique sombras nem efeitos.
- Sobre fotografia: use `lockup-dark.png` e escureça a imagem para contraste WCAG AA.
- Para favicons/app icons, prefira `symbol.svg`.

### Quando usar cada uma

- **Lockup completo (com "CONSULTORIA")**: institucional, primeira impressão, cabeçalho oficial.
- **Wordmark (sem tagline)**: dentro de produto, em espaços apertados, navegação.
- **Símbolo isolado**: favicon, avatar, marca d'água, ícones de UI, loading.
